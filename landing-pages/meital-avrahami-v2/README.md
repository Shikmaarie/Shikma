# דף נחיתה, גרסה B: וובינר חינמי של מיטל אברהמי

גרסה בהירה ואוורירית לפי הרפרנס השני: אבן, מרווה וטרקוטה, ענפי זית שנחתכו
מתמונת ההירו, וצילום של מיטל בסקשן "בהנחיית". גרסה A נמצאת ב-`../meital-avrahami/`.

ההגדרות זהות לגרסה A (ראו את ה-README שם): `FORM_ENDPOINT` בראש הסקריפט,
קישור למדיניות השימוש, וצילומי מסך של עדויות בבלוק `.shots`.

הטופס שולח גם `variant=B`, כך שאם מריצים את שתי הגרסאות במקביל אפשר לראות
במערכת הדיוור איזו מהן ממירה יותר.
