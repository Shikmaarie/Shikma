# דף נחיתה: וובינר חינמי של מיטל אברהמי

„העבר שלא חווית, ועדיין מנהל לך את החיים” · 5.11.26 · 20:00

דף סטטי בקובץ אחד (`index.html`) + תיקיית `assets/`. אין תלות ב-Next.js של האתר
הראשי: אפשר להעלות את התיקייה כמו שהיא לכל אחסון (Netlify, Vercel, cPanel) או
להדביק כ-HTML מותאם בבונה אתרים.

## לפני עלייה לאוויר

1. **לחבר את הטופס.** בראש ה-`<script>` בתחתית הקובץ:
   `const FORM_ENDPOINT = "";` צריך לקבל כתובת webhook (Make / Zapier /
   Google Apps Script / מערכת הדיוור). כל עוד היא ריקה מופיע בפינה תג
   „טופס לא מחובר” והלידים **לא נשמרים**.
   השדות שנשלחים (POST, form-urlencoded): `name`, `email`, `phone`, `consent`,
   `webinar`, `page`, `submitted_at`, וגם `utm_*` / `fbclid` / `gclid` אם יש בכתובת.
2. **קישור למדיניות השימוש** בתיבת האישור ובפוטר (כרגע `href="#"`).
3. **צילום של מיטל** במקום האיור של האבנים: הוראות בהערה בתוך `.portrait`.
4. **צילומי מסך של עדויות**: לשים ב-`assets/testimonials/` ולבטל את ההערה בבלוק `.shots`.
5. **פיקסל / אנליטיקס**: אם `fbq` או `gtag` טעונים בדף, נשלח אוטומטית
   `CompleteRegistration` / `sign_up` אחרי הרשמה.

## מה יש בדף

- ספירה לאחור לשידור (שעון ישראל, מתחלף ל„השידור התחיל/הסתיים”)
- כפתור הרשמה צף במובייל, שנעלם כשהטופס על המסך
- ולידציה לטלפון נייד ישראלי, honeypot נגד בוטים
- אחרי הרשמה: הוספה ליומן Google או קובץ ics (עם תזכורת חצי שעה לפני)
- `assets/og.jpg`: תמונת שיתוף לוואטסאפ/פייסבוק. ב-`og:image` צריך כתובת
  מלאה (https://...) אחרי שיש דומיין.
