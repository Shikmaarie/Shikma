# דף נחיתה: וובינר חינמי של מיטל אברהמי

וובינר "העבר שלא חווית" · חמישי 5.11.2026 · 20:00 (שעון ישראל) · בזום

דף סטטי: HTML, CSS ו-JavaScript בתוך הקבצים עצמם, בלי build ובלי ספריות.
התמונות והסרטונים **לא** בתוך הקוד: הם בתיקייה `assets/`, וצריך להעלות אותה יחד עם הקבצים.

## מה יש בחבילה

| קובץ | מה זה |
| --- | --- |
| `index.html` | דף הנחיתה |
| `thanks.html` | דף התודה שמגיעים אליו אחרי הרשמה, עם הוספה ליומן |
| `webinar.ics` | אירוע יומן לאייפון ול-Outlook (דף התודה מקשר ל-`/webinar.ics`) |
| `assets/` | תמונות, לוגו, רקעים, תמונת שיתוף (`og.jpg`) |
| `assets/testimonials/` | 4 סרטוני עדות (mp4) עם תמונות פתיחה, ו-9 צילומי וואטסאפ |

כל הנתיבים יחסיים (`assets/...`), חוץ מ-`/webinar.ics` שמניח שהקבצים יושבים בשורש הדומיין.
אם הדף עולה לתת-תיקייה, צריך לשנות את הנתיב הזה ב-`thanks.html`.

## חובה לפני עלייה לאוויר

1. **לחבר את הטופס.** בתחתית `index.html`, בתחילת ה-`<script>`:
   `const FORM_ENDPOINT = "";`
   צריך לשים כתובת webhook (Make, Zapier, Google Apps Script, CRM או מערכת דיוור).
   כל עוד הערך ריק, הפרטים **לא נשמרים**, ובפינת הדף מופיע תג חום "טופס לא מחובר (מצב תצוגה)".
   - נשלח `POST` בפורמט `application/x-www-form-urlencoded`.
   - שדות: `name`, `email`, `phone` (ספרות בלבד), `consent`, `webinar` (`2026-11-05`), `variant`, `page`, `submitted_at`.
   - נשלחים גם `utm_*`, `fbclid`, `gclid` אם הם קיימים בכתובת.
   - יש שדה מלכודת לבוטים (`website`, מוסתר). אם הוא מלא, הטופס לא נשלח.
   - אחרי תשובה תקינה (2xx) הגולש עובר ל-`thanks.html`.
   - כדאי לשלוח ליד בדיקה אחד מקצה לקצה.
2. **פיקסל מטא ו/או Google Analytics.** אין כרגע קוד מעקב בדף.
   - צריך להוסיף את קוד הבסיס ב-`<head>` של שני הדפים.
   - הדף כבר יורה `fbq("track","CompleteRegistration")` ו-`gtag("event","sign_up")` אחרי הרשמה, אם הם טעונים.
   - אפשר גם להגדיר את `thanks.html` כדף המרה.
3. **מדיניות פרטיות.** שני קישורים מצביעים כרגע על `#`: בתיבת האישור בטופס ובפוטר.
   צריך דף מדיניות ולקשר אליו משני המקומות.
4. **דומיין.** ב-`<head>` של `index.html` יש כתובות מלאות של `https://meital-avrahami.vercel.app/`
   (`og:url`, `og:image`). צריך להחליף לדומיין הסופי, אחרת תצוגת הקישור בוואטסאפ ובפייסבוק תמשוך מהכתובת הישנה.

## הגדרות שרת

- **סרטונים:** לשרת `.mp4` עם `Content-Type: video/mp4` ותמיכה ב-Range requests. אצל רוב השרתים זה ככה כברירת מחדל.
  הסרטונים בפורמט H.264 עם AAC, מכווצים (1.2 עד 5.8MB), ונטענים רק כשלוחצים על נגן.
- **יומן:** לשרת `webinar.ics` עם `Content-Type: text/calendar; charset=utf-8`.
- **מטמון:** את קבצי ה-HTML עדיף לשרת עם `Cache-Control: max-age=0, must-revalidate`, כדי ששינויים יופיעו מיד.

## פרטי האירוע בקוד

בשני הקבצים (`index.html` ו-`thanks.html`):

```js
const EVENT_START = new Date("2026-11-05T20:00:00+02:00");
const EVENT_MINUTES = 90;   // אורך השידור, לאישור מול מיטל
```

אם המועד או האורך משתנים, לעדכן בשני הקבצים וגם ב-`webinar.ics` (שעות ב-UTC: `DTSTART:20261105T180000Z`).

## מה הדף עושה

- ספירה לאחור בטופס, שמתחלפת ל"השידור התחיל / הסתיים".
- ולידציה: שם, מייל, נייד ישראלי (05X), ואישור דיוור חובה.
- כפתור הרשמה צף במובייל, שנעלם כשהטופס על המסך.
- עדויות:
  - במובייל 4 צילומי וואטסאפ, וכפתור "לעוד עדויות" שפותח את השאר.
  - לחיצה על צילום פותחת אותו בגדול.
  - קו זהב מצטייר סביב כל עדות כשהיא נכנסת למסך.
- הדף נפתח תמיד בראשו, גם אחרי רענון או מקישור עם `#`.
- מכבד `prefers-reduced-motion`: בלי אנימציות למי שביקש.
- תוכן גלוי גם בלי JavaScript (האנימציות מופעלות רק כשיש JS).
