# דף נחיתה „קשרים ושת״פים” — בריף ל-Lovable

שני קבצים:

- `connections.html` — תצוגה מקדימה. נפתחת בדפדפן, לא נדחפת ל-Lovable.
- `ConnectionsLanding.tsx` — הרכיב שנדחף. React + TypeScript + Tailwind + shadcn/ui.

---

## 1. טוקנים — להוסיף ל-`src/index.css`

```css
:root {
  --forest:     173 75% 19%;   /* #0c544c */
  --forest-dp:  173 75% 14%;   /* #093f39 */
  --forest-lt:  176 67% 26%;   /* #16706a */
  --parchment:   44 79% 96%;   /* #fdf9ee */
  --sand:        38 44% 59%;   /* #c5a469 */
  --sand-lt:     41 45% 85%;   /* #eadfc8 */
  --gold-lt:     40 67% 78%;   /* #edd4a2 */
}
```

## 2. `tailwind.config.ts`

```ts
theme: {
  extend: {
    colors: {
      forest:    { DEFAULT: "hsl(var(--forest))",
                   dp: "hsl(var(--forest-dp))",
                   lt: "hsl(var(--forest-lt))" },
      parchment: "hsl(var(--parchment))",
      sand:      { DEFAULT: "hsl(var(--sand))", lt: "hsl(var(--sand-lt))" },
      "gold-lt": "hsl(var(--gold-lt))",
    },
    fontFamily: { sans: ["Heebo", "system-ui", "sans-serif"] },
  },
}
```

## 3. גופן

**Heebo** בלבד, משקלים 400 / 500 / 700 / 900. אין גופן שני בדף.

```html
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Heebo:wght@400;500;700;900&display=swap" rel="stylesheet">
```

הדף כולו RTL — `dir="rtl"` על ה-wrapper הראשי (כבר בקומפוננטה).

## 4. התמונות — ארבע, כולן ב-`public/lp/`

| שם הקובץ | איפה בדף | יחס | הערות |
| --- | --- | --- | --- |
| `lobby.png` | סקשן 2, רוחב מלא | 16:9 | אולם הכניסה. **שלטי הקשתות צרובים בתוך התמונה** — לא לצייר אותם ב-HTML |
| `racheli-yellow.png` | סקשן 2, שכבה מעל | לאורך ~2:3 | רקע שקוף. חורגת מתחת לקצה התמונה אל הקרם |
| `racheli-pink.png` | סקשן 6, בתוך הקשת | ריבועי | רקע שקוף |
| `gold-money.png` | סקשן 4, רקע שני הכרטיסים | 16:9 | יושב מתחת לשכבת הטורקיז |

עד שקובץ מועלה, ה-`<ImageSlot>` מציג את שם הקובץ הצפוי במקומו — כך שמשבצת ריקה תמיד מסבירה את עצמה במקום להיראות כתמונה שבורה. אין צורך לשנות קוד אחרי ההעלאה; הנתיבים כבר מצביעים נכון.

**שתי הדמויות בסקשן 2 מונחות זו על זו.** `racheli-yellow.png` יושבת בדיוק מעל הדמות שכבר קיימת ב-`lobby.png`, וחורגת מתחת לקצה. אם אחרי ההעלאה היא נראית כפולה או מוסטת — לכוונן את `bottom-[-14%]` ואת `h-[116%]`, או להסיר את ה-`ImageSlot` השני ולהשאיר את התמונה לבדה.

## 5. סדר הסקשנים

1. **Hero** — רקע `forest`, כפתור `sand` צף בפינה שמאל-עליון, כותרת לבנה בשלוש שורות, שורה רביעית ב-`sand` וגדולה ב-10%, באנר `sand` מעוגל, שורת מטא נטויה
2. **רצועת התמונה** — `lobby.png` + הדמות החורגת, ואז גרפיקת הרשת על `parchment`
3. **אינטרו המועדון** — `parchment`, ממורכז, שש שורות שחלקן מודגשות, CTA
4. **„יש שתי דרכים לגדול”** — לבן, שני כרטיסים על `gold-money.png` מתחת לשכבת טורקיז
5. **„בהדרכה רחלי חדד תחשוף”** — לבן, חמישה כרטיסים: 3 למעלה, 2 ממורכזים למטה, עיגול `forest` על הקצה העליון
6. **„מי אני?”** — `forest`, טקסט מימין, פורטרט בקשת משמאל עם שני תגים לבנים
7. **„שמרו לי מקום בהדרכה”** — פאנל `parchment` על לבן, שלושה שדות
8. **סיום** — `forest`, ציטוט עם גרש גדול ב-`sand`, רשת בתחתית

## 7. מדיניות פרטיות

`PrivacyPolicy.tsx` — עמוד נפרד בנתיב `/privacy`, מקושר משני צ׳קבוקסים מתחת לטופס.

הנוסח מבוסס על התבנית של עורכת הדין, מותאם לעסק של רחלי: „שירותים משפטיים”
הוחלף בהדרכות, קורסים וליווי עסקי, ופרטי משרד עורכי הדין הוחלפו בפרטיה של רחלי.

**שני צ׳קבוקסים מתחת לטופס, ובכוונה נפרדים:**

1. אישור מדיניות הפרטיות — **חובה** (`required`)
2. הסכמה לדיוור שיווקי — **לא חובה**

ההפרדה נדרשת: סעיף 30א לחוק התקשורת דורש הסכמה מפורשת ונפרדת לתוכן שיווקי,
ואסור להתנות את ההרשמה עליה.
