# תיק עבודות — שקמה אושרי אריה

אתר סטטי עצמאי, קובץ אחד: `index.html`. אין שלב בנייה, אין תלויות.
הכול (CSS ו-JS) יושב בתוך הקובץ; מבחוץ נטען רק גופן Heebo מ-Google Fonts.

**שים לב:** התיקייה הזו **אינה** חלק מהאתר של רחלי חדד שיושב בשורש הריפו.
היא אתר נפרד לגמרי, ואפשר להעלות אותה לדומיין משלה.

## צפייה מקומית

פשוט לפתוח את `index.html` בדפדפן, או:

```bash
cd portfolio && python3 -m http.server 8080   # http://localhost:8080
```
