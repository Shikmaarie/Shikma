# דף נחיתה: ענת שלו, מתקשרים מיניות בריאה

דף סטטי עצמאי (HTML + CSS + מעט JS), לא חלק מאתר Next.js של רחלי חדד שבשורש הריפו.
פותחים את `index.html` בדפדפן, או מעלים את התיקייה כמו שהיא לכל אחסון סטטי (Netlify, Vercel, GitHub Pages).

## לפני עלייה לאוויר

1. **WhatsApp**: למלא `WHATSAPP_NUMBER` בראש ה-`<script>` (פורמט 9725XXXXXXXX). כל עוד ריק, הכפתורים פותחים WhatsApp בלי נמען.
2. **רשתות ומייל**: למלא את `LINKS` באותו מקום. אייקון בלי קישור מוצג מעומעם ולא לחיץ.
3. **תמונה שנייה של ענת** (אודות): להחליף את `.photo-slot` ב-`<img src="assets/anat-about.jpg">`.
4. **המלצות**: שלושת הכרטיסים הם placeholder. רק המלצות אמיתיות, עם אישור.

## נכסים

- `assets/anat-hero.jpg`: הצילום של ענת (הלוגו צרוב בתמונה המקורית).
- `assets/logo.png`: הלוגו, חתוך מרקע לבן לרקע שקוף.
- `assets/illustration-*.jpg`: האיורים שסופקו.
