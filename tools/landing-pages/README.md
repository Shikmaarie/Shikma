# מרכז דפי הנחיתה

כלי ניהול פנימי לצוות: כל דף נחיתה של רחלי, דף התודה שאליו הוא מוביל,
וכל העיצובים לממומן שרצים עליו — במקום אחד.

הכלי מתפרסם כ־Artifact ולא כחלק מהאתר. הקובץ `index.html` הוא המקור;
מבנה הקובץ הוא תוכן ה־`<body>` בלבד — סביבת הפרסום עוטפת אותו ב־doctype
וב־`<head>`, ולכן אין בו תגיות `<html>`, `<head>` או `<body>`.

## פרסום ועדכון

מפרסמים עם כלי ה־Artifact על נתיב הקובץ הזה. פרסום חוזר על אותו נתיב
מעדכן את אותה כתובת. היכולות שהעמוד מצהיר עליהן:

| יכולת | למה |
| --- | --- |
| `db` | מאגר משותף לכל הצוות — דפים, עיצובים ותצוגות מקדימות |
| `downloads` | הורדת תצוגה מקדימה של עיצוב |

## מבנה הנתונים

| נתיב | מה יושב שם |
| --- | --- |
| `pages/{id}` | דף נחיתה: שם, קמפיין, סטטוס, כתובת הדף, כתובת דף התודה, תגיות, הערות |
| `creatives/{id}` | עיצוב: `pageId`, סוג (`ad`/`lp`/`thanks`), פלטפורמה, פורמט, סטטוס, קופי, קישור למקור, תצוגה מוקטנת |
| `previews/{id}` | תצוגה גדולה יותר של אותו עיצוב, נטענת רק בפתיחת התצוגה המלאה |

## מגבלות שכדאי לזכור

- **אין אחסון קבצים.** תמונה שמעלים נדחסת בדפדפן ל־JPEG ונשמרת כ־data URI
  בתוך המאגר: כ־25KB לאריח ועד כ־150KB לתצוגה המלאה. הקובץ המקורי אינו
  נשמר — לכל עיצוב יש שדה „קישור למקור” שאמור להצביע על הדרייב או הקנבה.
- **מסמך במאגר מוגבל ל־256KiB**, וסך המסמכים באמצע הזה הוא 5,000. לכן
  התצוגות מפוצלות לשני מסמכים, והאריחים נשמרים קטנים.
- **אין זיהוי משתמש.** כל אחד מקליד את שמו פעם אחת, והוא נשמר ב־localStorage
  של הדפדפן שלו ונרשם על מה שהוא מעלה. זו שקיפות, לא הרשאה.
- **כל מי שיכול לפתוח את העמוד יכול גם לכתוב בו.** עמוד שמצהיר על `db` הוא
  ארגוני־פנימי ואי אפשר לשתף אותו בפומבי, אבל אין בו „צפייה בלבד”.
- כשאין גישה למאגר (למשל בפתיחת הקובץ מקומית) הכלי עולה במצב הדגמה עם
  נתוני דוגמה מסומנים, ושום שינוי לא נשמר.
