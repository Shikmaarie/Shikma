# מרכז דפי הנחיתה

כלי ניהול פנימי לצוות: כל דף נחיתה של רחלי, דף התודה שאליו הוא מוביל,
וכל העיצובים לממומן שרצים עליו — במקום אחד.

## שתי גרסאות, אחת פעילה

| תיקייה | מה זה | מצב |
| --- | --- | --- |
| `site/` | **הגרסה הפעילה.** אתר סטטי על Netlify מול Supabase | בשימוש |
| `index.html` | הגרסה הראשונה, Artifact של Claude עם אחסון של Claude | קפואה |

הגרסה הראשונה נבנתה כשהמטרה הייתה כלי פרטי. היא הוחלפה כי Artifact עם
מאגר פתוח רק לחברי ארגון Claude של הבעלים — מה שחוסם קניית מדיה או
קופירייטרית שאינן שם — וכי בלי אחסון קבצים היא שמרה תצוגות דחוסות במקום
את הקבצים עצמם. אין לפרסם מחדש את `index.html`; לתקן רק את `site/`.

## פריסה

`site/` הוא אתר סטטי בלי שלב build: `index.html`, `supabase.js` (עותק
מקומי של supabase-js 2.116.0) ו־`netlify.toml`. מעלים בגרירה לפרויקט
`racheli-landing-pages` ב־Netlify, או מחברים את הריפו עם
base directory `tools/landing-pages/site` ובלי פקודת בנייה.

הספרייה שמורה בריפו ולא נטענת מ־CDN, כדי שהכלי לא ייפול בגלל תקלה אצל
צד שלישי.

המפתח שמופיע ב־`index.html` הוא ה־publishable key של Supabase. הוא נועד
לרוץ בדפדפן, וכל ההגנה נשענת על RLS — ראו `supabase/schema.sql`.

## מבנה הנתונים

| טבלה | מה יושב שם |
| --- | --- |
| `pages` | דף נחיתה: שם, קמפיין, סטטוס, כתובת הדף, כתובת דף התודה, תגיות, הערות |
| `creatives` | עיצוב: `page_id`, סוג (`ad`/`lp`/`thanks`), פלטפורמה, פורמט, סטטוס, קופי, קישור נוסף, נתיבי הקובץ והאריח |
| `app_team` | רשימת המיילים שמורשים להיכנס |

הקבצים יושבים בבאקט `creatives` בנתיב `<page_id>/<creative_id>/`: הקובץ
המקורי כמו שהוא, ולידו `thumb.jpg` שנוצר בדפדפן לתצוגת הרשת. לווידאו
נלכד פריים מהשנייה הראשונה. הבאקט פרטי, והדפדפן מקבל URL חתום לשעה.

## מגבלות שכדאי לזכור

- **כניסה אחת משותפת.** כל הצוות נכנס עם אותו חשבון, ולכן השם שכל אחד
  מקליד (נשמר ב־localStorage שלו) הוא מה שמבדיל ביניהם. זו שקיפות, לא
  הרשאה, ואי אפשר לתת למישהו „צפייה בלבד”.
- **חבר צוות ≠ חשבון מחובר.** גם מי שיש לו סשן תקף לא רואה כלום אם המייל
  שלו לא ב־`app_team`. זה מה שמגן במקרה שהרשמה עצמית פתוחה.
- **50MB לקובץ.** מגבלת הבאקט. קובץ גדול יותר נדחה בהודעה ברורה.
- מחיקת דף מוחקת את העיצובים שלו (cascade) ואת הקבצים מהאחסון.
- **הגנה מפני סיסמאות שדלפו כבויה** בפרויקט. שווה להדליק בלוח הבקרה של
  Supabase תחת Authentication, במיוחד לפני החלפת סיסמה.
