# ריל דף הנחיתה

מייצר סרטון אנכי 1080×1920 שבו דף הנחיתה רץ על מסך לפטופ, בתוך סצנה
בצבעי המותג. מיועד לאינסטגרם / ריל / סטורי.

הכלי עצמאי לגמרי: הוא לא חלק מאפליקציית Next, לא נכנס ל-build ולא משפיע
על האתר. אפשר להריץ אותו על כל URL.

## הרצה

```bash
cd tools/reel
npm install
npx playwright install chromium   # פעם אחת
npm run reel
```

הפלט: `tools/reel/out/reel.mp4`

## שני השלבים

`npm run reel` מריץ את שניהם ברצף, אבל אפשר להפריד:

| פקודה | מה קורה |
| --- | --- |
| `npm run capture` | פותח את הדף בדפדפן, מגלגל אותו כדי לעורר lazy-load ואנימציות, ומצלם צילום מלא ל-`out/page.png` |
| `npm run render` | מרכיב את הצילום על מסך הלפטופ, מרנדר 750 פריימים ומקודד ל-MP4 |

לצלם דף אחר בלי לגעת בהגדרות:

```bash
node capture.mjs https://example.com
```

## תצוגה מקדימה בלי לרנדר סרטון שלם

```bash
node render.mjs --preview 12     # שומר out/preview-12s.png
```

שימושי לבדוק קומפוזיציה, טקסטים וגדלים לפני שמחכים לרינדור מלא.

## דגלים

| דגל | מה הוא עושה |
| --- | --- |
| `--png` | פריימים חסרי אבדן במקום JPEG. איטי משמעותית, ההבדל כמעט לא נראה אחרי שאינסטגרם מקודדת מחדש |
| `--preview <שנייה>` | פריים בודד ל-PNG במקום סרטון |

משתני סביבה:

- `CHROMIUM_PATH` — נתיב לדפדפן, אם הוא מותקן מחוץ ל-playwright
- `FFMPEG_PATH` — נתיב ל-ffmpeg. אחרת נלקח מ-`ffmpeg-static`

## מה משנים ב-`config.mjs`

- `url` — הדף שמצולם
- `duration`, `fps` — אורך וקצב
- `stops` — כמה עצירות לאורך הדף. הקוד מצמיד כל עצירה לתחילת סקשן,
  כדי שהגלילה לא תיעצר באמצע פסקה
- `travelRatio` — כמה מכל מקטע זה תנועה וכמה עצירה
- `viewportWidth` — רוחב הדפדפן הווירטואלי. **קטן יותר = טקסט גדול יותר
  בסרטון.** 1280 הוא ברירת מחדל טובה; 1100 יגדיל את הטקסט
- `overlay` — הטקסט על הפריים

## אזהרת תוכן

הטקסט ב-`overlay` מופיע בפרסום. **לא להמציא שם תאריכים, מחירים, מספרי
משתתפים או הבטחות תוצאה.** ברירת המחדל מכילה רק את שם המותג והטאגליין
הרשמי. ראו `CLAUDE.md` בשורש הפרויקט.

## מוזיקה

הסרטון יוצא בלי פס קול. מוסיפים מוזיקה בעריכה (Reels, CapCut, Premiere),
או בשורת פקודה:

```bash
ffmpeg -i out/reel.mp4 -i music.mp3 -shortest -c:v copy -c:a aac out/reel-audio.mp4
```

## מגבלות ידועות

- אלמנטים דביקים (`position: fixed/sticky`) מוסתרים לפני הצילום, אחרת הם
  מצטלמים שוב ושוב לאורך הדף. אם דווקא רוצים אותם — `hideFixed: false`
- וידאו מוטמע בדף מצולם כפריים בודד קפוא. זה צילום סטילס, לא הקלטת מסך
- רינדור של 750 פריימים לוקח דקה עד כמה דקות, תלוי במחשב
- הצילום נעשה ב-`deviceScaleFactor: 2`. דף ארוך מאוד יכול לייצר PNG כבד
