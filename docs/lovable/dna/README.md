# ה־DNA של העושר — עיצוב מחדש לדף הנחיתה

היעד: פרויקט Lovable `4f9f9980-ed07-4825-9881-dd61ff3b3997`
(„Remix of כנס אונליין חינם עושים אהבה עם הפחד מכסף”), שמשרת את
`moneymindb.rachelihadad.co.il`. הסטאק שם הוא TanStack Start + Tailwind v4 +
shadcn/ui + Supabase.

## מה יש כאן

| קובץ | מה עושים איתו |
| --- | --- |
| `index.tsx` | מחליף את `src/routes/index.tsx` |
| `styles.append.css` | מחליף את בלוק הטוקנים של דף הנחיתה ב-`src/styles.css` |
| `assets/hero-bg.webp` | רקע ההירו החדש |
| `assets/logo-gold.webp` | לוגו הזהב „מכפילה עסקים · בונה אימפריות” |

התצוגה החיה של העיצוב: https://claude.ai/artifact/6S2ctZ5N5PwZtqo2npFUPE

## מה נשמר אחד לאחד ואסור לגעת בו

- `RavPageForm`, `RavPageInlineFallback`, `logFormLoad`, `pickField` — ה-iframe,
  ה-`document.write`, הגיבוי המקומי ושמירת הלידים ל-Supabase.
- `.rp-embed` ב-`styles.css`.
- פיקסל מטא ב-`src/routes/__root.tsx`.
- המסלולים `/privacy` ו-`/accessibility` ו-`AccessibilityWidget`.
- כל הקופי, שאושר על ידי רחלי.

## מה חדש

- מסגרת שחורה עם יריעת קריאה בהירה שצפה במרכז.
- טיפוגרפיית Assistant, גוף 19px, line-height 1.8, בלי letter-spacing על עברית.
- הטורקיז של המותג: `#0e4c52` עם `#87c7bc`. מעבר הצבע בכותרות מוגדר פעם אחת
  במשתנים `--g1/--g2/--g3` וכל `.lp-grad` שואב ממנו.
- הירו כהה עם תמונת הרקע החדשה. במובייל ובטאבלט ההמסה אל הרקע נעשית ב-`mask`
  ולא בשכבת שחור, כדי שהתמונה תישאר בבהירותה.
- פס אמינות: 18 שנות ניסיון · 1,000+ בעלי עסקים ומשפחות · 3 עסקים בשש ספרות.
- FAQ עם חמש שאלות, אקורדיון `<details>` בלי JavaScript.
- פרטי זום וקבוצת הוואטסאפ ליד כל כפתור מרכזי.
- ניסוח כפתור שונה לפי הסקשן שמעליו.

## מה עדיין דורש אישור של רחלי

- ניסוח התשובות ב-FAQ, במיוחד „ינסו למכור לי משהו?” — נכתב ולא אושר.
- ההבטחה „תצאו עם מפת ה־DNA הכלכלית שלכם מלאה” מחייבת תוצר בפועל ביום 3.
