# חבילת ה-Lovable של דף הנחיתה

מה שנדחף לפרויקט ב-Lovable, מוכן לאינטגרציה:

| קובץ | מה זה |
| --- | --- |
| `MoneyFearLanding.tsx` | הדף כקומפוננטת React + Tailwind, TypeScript, `@/` alias, `lucide-react` |
| `index.css.snippet.css` | טוקנים ב-HSL, רחצת האקוורל, טיפוגרפיית Rubik, ייבוא הפונטים |
| `tailwind.config.snippet.ts` | הרחבת `theme.extend` בשמות הצבעים והרדיוסים |

התצוגה לאישור היא ה-Artifact החי, לא הקבצים האלה.

## החלטות שכדאי להכיר

- **הטופס הוא ההטמעה של רב מסר**, לא טופס משלנו. תגית `<script>` בתוך JSX לא
  רצה אף פעם, ולכן הוא נטען מתוך `useEffect` לתוך div ייעודי, עם שמירה מפני
  הזרקה כפולה (StrictMode מריץ אפקטים פעמיים בפיתוח).
- **בלי shadcn/ui בכפתורים.** הם פילים מעוצבים של הקמפיין, ווריאנט Button של
  הפרויקט היה מושך אליו סגנון אחר. שאר הקונבנציות של Lovable נשמרו.
- **בלי framer-motion.** אנימציות הכניסה הן IntersectionObserver קטן שמכבד
  `prefers-reduced-motion` ומתחיל במצב גלוי אם אין תמיכה. זה חוסך תלות שלמה.
- **התמונות מיובאות מ-`@/assets/`.** שלושתן הועלו ל-Lovable ומצורפות להודעה.
- **גודל הטקסט הרץ** יושב ב-`--lp-body` ב-`index.css`. מספר אחד לשינוי.
