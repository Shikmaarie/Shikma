# דף הנחיתה בפיגמה — תוסף מקומי

התוסף הזה בונה את דף הנחיתה `/partnerships` בתוך פיגמה: טוקנים, סגנונות
טיפוגרפיה, קומפוננטות, פריים דסקטופ, פריים מובייל ומצב ההצלחה של הטופס.

## למה תוסף ולא חיבור ישיר

לשרת ה-MCP של פיגמה יש מכסה לפי תוכנית — **20 קריאות בחודש** בתוכנית Starter,
ובניית דף בגודל הזה דורשת הרבה יותר. תוסף שרץ מקומית מדבר עם אותו Plugin API
בדיוק, בלי מכסה ובלי תשלום.

**התנאי:** תוספים מקומיים רצים רק ב**אפליקציית הדסקטופ** של פיגמה (הורדה חינם
מ-figma.com/downloads). בדפדפן אי אפשר לייבא תוסף מקומי.

## הרצה

1. פותחים את אפליקציית הדסקטופ של פיגמה.
2. פותחים קובץ עיצוב כלשהו (או יוצרים חדש).
3. תפריט **Plugins → Development → Import plugin from manifest…**
4. בוחרים את `figma-plugin/manifest.json` מהתיקייה הזאת.
5. **Plugins → Development → רחלי חדד — דף נחיתה**.

הבנייה לוקחת כמה שניות. בסוף מופיעה הודעה: „הדף נבנה בהצלחה”, או ספירת אזהרות
— במקרה כזה הפירוט נמצא ב-**Plugins → Development → Open console**.

## מה נוצר

| עמוד | תוכן |
| --- | --- |
| `דף נחיתה — שת״פים` | `Landing — Desktop 1440`, `Landing — Mobile 390`, `Registration — success` |
| `רכיבים` | Chip, CTA / Primary, Stat, Field, Curriculum Card |

בנוסף נוצרים:

- **אוסף משתנים `Brand`** במוד `Light` — כל צבעי הפלטה הבהירה, עם scopes
  מתאימים (רקעים, טקסט, מסגרות). כל צבע בדף קשור למשתנה, לא מוטבע כהקס.
- **סגנונות טקסט** — `Display/H1…`, `Body/…`, `Label/…`, `Stat/…`.

הכל בנוי ב-Auto Layout. פריים הדסקטופ מורכב מ-instances של הקומפוננטות, כך
שעריכה בקומפוננטה מתפשטת לכל השימושים.

## עדכון אחרי שינוי בקוד

הטקסטים **לא** כתובים בתוסף — הם נשאבים מקבצי המקור של האתר, כדי שלא ייווצר
פער בין הקוד לעיצוב. אחרי שינוי ב-`src/data/partnerships.ts` או
ב-`src/data/site.ts`:

```bash
node figma-plugin/build.mjs   # מזריק מחדש טקסטים + תמונה ל-code.js
```

ואז מריצים שוב את התוסף בפיגמה (על עמוד ריק — הוא יוצר עמודים חדשים, לא
מעדכן קיימים).

`build.mjs` מזריק שלושה בלוקים מסומנים ב-`code.js`: הטקסטים, פרטי המותג,
והפורטרט כ-base64. **אין לערוך את הבלוקים האלה ביד.** התמונה מוטמעת בקובץ
כי המניפסט חוסם גישה לרשת — התוסף לא מוריד כלום.

## הערות

- **הבנייה נבדקה מול מוק של ה-Plugin API**, לא מול פיגמה עצמה (אין מכסה
  לבדיקה). המוק אוכף את הכללים שנוטים להישבר בשקט: `FILL` על ילד שההורה שלו
  עדיין hug, כתיבת טקסט תחת פונט שלא נטען, צבעים מחוץ לטווח 0–1, ו-alpha
  שהוברח לתוך צבע של paint. בהרצה האחרונה: 0 הפרות, וכל 77 מחרוזות התוכן
  מופיעות בעיצוב.
- **פעולות עיצוב לא קריטיות עטופות ב-try** ונאספות כאזהרות. אם גרסה מסוימת של
  פיגמה דוחה משהו קוסמטי, הדף עדיין נבנה.
- הפונטים הם Heebo ו-Frank Ruhl Libre, שניהם Google Fonts הזמינים בפיגמה.
- **RTL:** לפיגמה אין כיוון פריסה, אז כל שורה אופקית מסודרת הפוך — הפריט
  הראשון בסדר הקריאה הוא הילד האחרון, כלומר הימני ביותר.
